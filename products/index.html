Products

Open-source software implementing Genefold’s spectral methods. All links point to the primary repositories; check each repository for releases, licences, and documentation.

Core library

ArrowSpace

Spectral vector search in Python and Rust: graph analysis, bounded spectral scores, and manifold-coherent retrieval.

 Agents

arrowspace-mcp

Model Context Protocol server exposing spectral search to LLMs and agents. Apache-2.0.

 Workflows

arrowspace-skills

Prompt-driven skills for using arrowspace and pyarrowspace in agent workflows.

 Services

arro-server

Arrow Flight RPC server for high-throughput spectral artifact exchange over a binary columnar protocol.

 Tooling

arrowspace_tuner

Hyperparameter optimisation and benchmark tooling for spectral pipelines: tau-modulation profiles and graph-wiring parameters.

 Live demo

CVE Search Engine

Spectral search over the National Vulnerability Database, with live tau modulation and side-by-side baseline comparison.
